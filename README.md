# Assets for verl-project/verl-omni PR #744 (DiffusionART)

Figures and raw per-step metrics referenced from the PR discussion. Generated by the LTX-2.3 T2AV like-for-like runs
(OmniNFT vs DiffusionART K=8 / K=2) and the MiniMax-H3 runs described there.

- `gpu-hours/` — validation reward vs cumulative GPU-hours (primary) and vs step, with the CSV/JSON behind it and the script that draws it (2026-11-04); FlowGRPO and DiffusionART-Flash arms pending.
- `curves_step50.png` — four-panel figure, first 50 steps (training reward, paired per-step Δ, validation, step-50 components).
- `curves.png` — earlier version through step 30.
- `metrics.json` / `table.md` — every logged key per step for the three LTX runs, **as far as it was archived**: OmniNFT steps 0–150, DiffusionART K=8 steps 0–26, K=2 steps 0–45. The later per-step logs of both ART arms lived on the training nodes and were not archived before the nodes were released, so this file cannot be extended; `curves_step50.png` was drawn from those logs. The step-10–50 validation rewards quoted in the PR (K=8 11.72 / 11.91 / 12.42 / 12.83 / 12.76, K=2 9.46 / 11.11 / 11.35 / 11.70 / 11.73, OmniNFT 10.73 / 11.55 / 12.28 / 12.94 / 13.13) were recorded from the run logs at the time. (Coverage corrected 2026-11-01 after review.)
- `ltx23-step50/` — frame sheets, LTX-2.3 step 50, base / OmniNFT / ART K=8 / ART K=2, 16 same-seed prompts.
- `h3-step0-vs-10/` — frame sheets, MiniMax-H3 step 0 / NFT step 10 / ART step 10, 16 same-seed prompts (CLAP + ImageBind rewards).
- `h3-5rew-art-step0-vs-10/` — frame sheets, MiniMax-H3 with the five-reward set, DiffusionART step 0 vs 10, 16 same-seed prompts.
- `h3-5rew-art-step0-10-20/` — frame sheets, MiniMax-H3 five-reward DiffusionART step 0 · 10 · 20, 16 same-seed prompts.
- `h3-5rew-art-step0-10-20-30/` — frame sheets, MiniMax-H3 five-reward DiffusionART step 0 · 10 · 20 · 30.
- `h3-5rew-art-step0-to-40/` — frame sheets, MiniMax-H3 five-reward DiffusionART step 0 · 10 · 20 · 30 · 40.
- `h3-5rew-art-step0-to-50/` — frame sheets, MiniMax-H3 five-reward DiffusionART step 0 · 10 · 20 · 30 · 40 · 50.
- `h3-5rew-art-step0-to-60/` — frame sheets, MiniMax-H3 five-reward DiffusionART step 0 · 20 · 40 · 50 · 60 (final).
